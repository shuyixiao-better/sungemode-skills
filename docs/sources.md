# 来源与产品化设计

项目受 [邵艾伦 Alan × 孙宇晨：年轻人如何抓住 AI 时代的机会？](https://x.com/AlanShao111/status/2108406850727076182) 公开访谈启发。本次实现参考了项目发起者在“开源项目命名建议”对话中提供的完整字幕，并核对以下时间段。字幕可能包含转写错误，时间锚点以发起者提供版本为准；未独立逐句核验公开视频。

| 方法灵感 | 字幕时间 | 本项目的设计 |
|---|---|---|
| 用 Markdown 保存资料，让不同 AI 接手 | 00:07:28–00:07:48 | 本地个人档案、工作区索引与跨 Agent 交接 |
| 整理现状，让 AI 辅助找方向，结合新数据调整 | 00:17:21–00:21:18 | 约束驱动的机会选择与持续复盘 |
| 先探索地图、造斥候，再配置资源 | 00:43:31–00:45:16 | 客户、替代方案、渠道和成本的机会地图 |
| 先尝试，获得体验后决定进一步投入 | 03:19:11–03:19:29 | 小规模实验与继续/停止条件 |

“七天周期”“E/H 编号”“预算上限”“证据分类”“预设阈值”“五个技能和记录模板”是 Owen 对这些方法的产品化设计，不能作为受访者原话或已存在的软件功能引用。七天是可调整的默认周期；字幕中关于长期积累数据的表达不意味着用户必须等待数月才能开始。

访谈是方法灵感，不是客户需求、竞品价格、政策或商业可行性的证据。运行技能时，这些事实须另行查证；无法查证就标为未知或待验证。示例为虚构案例，不把模拟计划包装成真实客户反馈。

本项目由 Owen（GitHub: [shuyixiao-better](https://github.com/shuyixiao-better)）独立开发，与受访者、主持人及其公司无隶属或背书关系。仓库不分发完整字幕、公开视频或个人访谈资料。项目代码和原创文档的 MIT 许可不覆盖第三方内容。
