# 健康与复利


## 访谈观点与适用边界

- **碳基服务器、长期行动能力**：维护身体的设备比喻帮助理解休息和活动的重要性，不构成医学机制或因果证明。
- **量化生活**：照片、睡眠、运动与穿戴设备记录可用于观察；热量/活动消耗是估算，不是精确测量，设备标签不等于临床诊断。
- **主动健康管理**：关注日常习惯和风险因素；具体检查与治疗应按个人情况和可靠医学依据确定。
- **薄肌与身体形象**：外形偏好、健身表现和健康分别讨论；不将某种体型定义成健康或价值标准。
- **年轻、时间与寿命优势**：较长行动时间是嘉宾对机会的解释，不保证个人寿命或未来技术延寿。

## 用于用户的工作方法（项目设计）

先问当前要改善什么、可承受的安排、已有相关记录与限制。资料不足时从简短记录或一般生活习惯入手；不要求用户上传全部健康数据。涉及具体健康建议时核查可靠公共卫生/专业来源，不根据字幕推导营养剂量、减脂热量目标或治疗。

习惯试验关注可执行性、睡眠/活动记录与主观感受；不要用短期体重变化、穿戴分数或收入推断健康效果。计划出现明显不适时暂停新增训练并根据症状寻求适当帮助；具体症状请求不沿用普通习惯计划。

交付：记录中的事实与估算、一个可持续的习惯或记录动作、负担、观察与调整条件。共享资源安排中不要用健康计划挤占睡眠，也不要为商业验证牺牲恢复。

## 身体维护：找出计划中最先失守的环节

这套过程用于生活安排和习惯观察，不代替症状评估或治疗。

1. **明确要改善的体验**：用户是想少疲惫、安排规律、提高活动可持续性，还是只追求外形？分别写目标，不把它们合成“更健康”。
2. **看真实日程**：读取或请用户描述典型一天，找出工作/照护、休息机会、已有活动与准备成本。先检查新增目标是不是把时间挤满，不能直接归因为自律不足。
3. **选择一个可改变的环节**：例如给既有散步留出时间、减少记录负担，或调整晚间工作安排。涉及具体运动/营养建议时另查可靠依据，避免把访谈经验当处方。
4. **写最低可执行版本与退路**：条件适合时做什么，工作临时增加时缩减哪项新增任务；不以补做、挤占休息来维持打卡。
5. **观察负担和趋势**：记录执行、日程影响和用户感受。周末检查可持续性；生理效果需要合适的时间与证据，不用短周期宣称因果。

交付一份实际日程调整：原来哪里冲突、挪动什么、占多少时间、什么情况暂停/求助、何时复盘。若日程和症状未知，给条件分支，别假定用户熬夜或缺乏运动。

例：用户“收入不错但很累”，先检查是否工作时长过大、照护压力增加、恢复被挤占或出现需要专业关注的症状；可能应减少副业目标，而不是再安排一套健身任务。
