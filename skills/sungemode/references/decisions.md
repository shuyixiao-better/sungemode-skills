# 决策与探索


## 访谈观点与适用边界

- **先探地图、低成本先验证**：重大选择先获取能改变决定的信息；低成本验证是项目对比喻的提炼。
- **全球视野、逐水草而居**：比较不同地区的需求与机会，也计入语言、资格、签证、税务、照护与迁移成本。稳定和地方积累也有价值。
- **兴趣、专长与长期投入**：探索后选择适合深钻的方向，兴趣不等于能力证明。
- **反馈、调优、信息价值与调查边界**：调查按能否改善选择衡量；为下一步定义停止调查的条件，避免永远搜集资料。
- **不可逆投入、小规模试验、低起点与真实约束**：保留纠错空间；既有投入少可能便于换路，但贫穷会限制试错能力，不能浪漫化。

## 用于用户的工作方法（项目设计）

比较维持现状及少量备选，分别列收益目标、现金/时间、可逆性、责任影响、最关键未知。先处理会淘汰选项的硬约束，再收集最可能改变排序的信息。把咨询、短期体验、样品等小试验与辞职/迁居等重承诺分开。

交付：选项表、当前倾向与条件、下一次信息获取或小试验、最大可承受损失、复盘/停止调查日期。就业机会需独立验证，不能由副业指标代替；健康与关系也不以付费作为验证指标。

## 探图：从未知到下一次投入

围绕一个决定执行以下过程，按问题删减：

1. **定义这次下注**：具体要选什么、何时必须决定、哪些后果难以撤回。探索兴趣和辞职是不同规模的下注。
2. **画已有地图**：列备选路线（含维持现状）、入口条件、资源和责任；将自述能力与已证明能力分开。
3. **找能改变排序的未知**：每个未知写“若答案为 A/B，会怎样改变选择”。不会影响决定的资料不优先收集。
4. **派出一个斥候**：选择一个成本可承受的调查或体验，写获取什么信息、时间/现金上限、会回来什么证据。不能虚构访谈、申请结果或体验。
5. **回报后再下注**：证据改善了哪个判断？下一步是继续调查、尝试、投入还是维持现状？到预定日期仍缺关键证据，可延期或选可逆方案，不用分数填补未知。

职业转向的斥候可以是分析实际岗位要求、完成小作品或在授权后询问相关从业者；先根据用户资源选一种，不默认购买课程或联系陌生人。

交付可以是一段话：**“在投入 X 前，先用 Y 获取 Z；若观察到 A 则继续，B 则调整，信息不足则暂缓。”** 数值按用户约束提出，不能替用户接受损失。

## 逐水草而居：设定换路条件，而非不停迁移

比较当前环境与备选环境中的实际机会、进入条件、已有积累和关系责任。写出什么变化值得重新评估，例如需求长期下降、资格条件改变或照护安排变化；再选择远程探索、短期体验、分阶段调整或保持稳定。机动性是保留选择，不要求用户迁居。查证岗位、签证或税务等事实后才用于判断，不把环境不适应直接归因为个人失败。
