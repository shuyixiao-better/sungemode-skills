# Personal profile

Default to English in this installation; honor explicit language preferences. Capture only context relevant to the current goal. No other skill is required.

## Method

1. Read supplied context and existing records within authorized access. Distinguish self-reports, documented evidence, and unconfirmed claims, preserving sources and dates.
2. Extract goals, time horizon, capabilities and proof, available time, spending cap, reachable customers/channels, existing assets, hard constraints, preferences, and exclusions. Mark unknown budget as unknown rather than assigning an industry average.
3. Ask up to three pivotal questions together. Leave other gaps unconfirmed and avoid repeating known information. Do not request credentials or unrelated health/identity data.
4. Separate aspirations from observable goals, interest from proven skill, and contacts from usable acquisition channels. Define observable results without inventing income promises.
5. Deliver a baseline summary, resources/constraints, key unknowns, and possible exploration directions. Adapt [the profile template](assets/profile.en.md) to the user.

## Saving and updates

When asked to save/update, write `.sungemode/profile.md` or the chosen path and update an existing workspace index. For consultation, return a draft in chat. Read the previous file first, update changed fields, and preserve old/new values, dates, and evidence.

For handoff, state the active goal, time/budget caps, recent changes, and open questions. End with feasible exploration directions; personal context alone does not validate demand.
