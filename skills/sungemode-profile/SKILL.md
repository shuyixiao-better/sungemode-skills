# 个人档案｜了解你

默认简体中文；遵从用户明确的语言偏好。仅处理与当前目标有关的现状，不需要其他技能。

## 工作方法

1. 读取用户给出的信息与已授权访问的现有档案。区分“用户自述”“有材料支持”“待确认”，保留来源和时间。
2. 提取目标、期望时间范围、技能及作品证明、可投入时间、预算上限、可接触客户/渠道、已有资产、硬约束、偏好和不做的事情。预算未知就写未知，不用行业平均替用户填数。
3. 集中询问最多三个真正影响后续选择的问题。其余空缺保留待确认；已经知道的不要再问。不要求提供账户、密码或与任务无关的健康/身份数据。
4. 区分愿望与可验证目标、兴趣与已证明能力、联系人与可实际使用的获客渠道。每个目标给出可观察结果，避免把“多赚钱”擅自改成具体收入承诺。
5. 输出现状摘要、资源/约束表、主要未知与下一步需要验证的方向。使用 [档案模板](assets/profile.md)，按用户情况删减字段。

## 保存与更新

用户要求保存/更新时写入 `.sungemode/profile.md` 或指定路径，并更新已有工作区索引。只是咨询时在对话输出档案草稿。先读旧文件，只更新已变化字段；记录旧值、新值、日期、依据，避免把历史事实改写。

跨 Agent 交接时明确当前目标、预算/时间边界、最近变化和需要接着确认的问题。用“现状支持哪些探索”收尾，不从个人资料直接断言市场需求成立。
