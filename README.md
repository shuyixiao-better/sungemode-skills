结合你的处境，梳理认知、决策、AI 学习、商业、财富、健康与人生体验，给出有依据、符合时间与预算上限的下一步。既可以全面盘点，也可以只解决一个问题，或根据已有记录复盘。原来的创业、副业和七天验证流程继续保留；Markdown 记录让不同 Agent 接着做。

## 项目理念

孙哥模式把访谈里的七个理念，整理成能用于个人选择、行动和复盘的方法：

- **探地图**：先了解选项与关键未知，减少盲目行动。
- **AI**：扩大信息处理能力，帮助整理资料、比较路径和持续学习。
- **黄毛理论**：分清有效质疑与无效压力，让独立判断有依据地保留下来。
- **逐水草而居**：关注环境变化，保留调整方向的空间，也考虑稳定与迁移的成本。
- **健康管理**：照顾身体与恢复，让长期行动能够持续。
- **财富自由**：增加自主选择的余地，让时间和生活安排更接近自己的意愿。
- **体验论**：承认无法提前理解整个世界，通过体验与反馈继续认识自己和世界。

这些理念用于全面盘点、职业与项目选择、学习安排、生活习惯、财富目标、关系和创造。技能会把它们落到具体问题、可承受的下一步和复盘条件上；用户无需先掌握所有概念。

## 先看一个用法

```text
开启孙哥模式，帮我做一次全面盘点。我做了五年开发，想探索 AI 副业，
也想改善学习安排，并给关系和休息留时间。扣除工作与生活责任后，
每周还有七小时，试验预算最多 200 元，不想辞职。
请覆盖七个主题，信息不足的地方写未知，最多问三个关键问题。
全部行动共用七小时和 200 元，不要每个领域各安排一套。
```

你会得到七方面的现状与未知、跨领域取舍、优先行动、时间/预算合计和复盘条件。健康与财务可以只提供摘要或范围；不必上传全部数据。具体问题不会强行套全面报告。

查看 [人生盘点中文演示](examples/life-baseline.zh-CN.md) / [English demo](examples/life-baseline.en.md)，或原来的 [七天项目验证](examples/seven-day-plan.zh-CN.md)。示例是虚构场景，展示结构与计算，不代表实际使用验证、调研或成交。

## 七个主题与三个使用入口

| 主题 | 可以用来做什么 |
|---|---|
| 认知升级 | 检查旧观念、外界质疑、路径依赖与反证 |
| 决策与探索 | 比较职业、城市与项目选择，先探图再投入 |
| AI 与知识 | 整理个人资料、学习、查证与跨工具接续 |
| 商业与技术 | 探索需求、全球市场、数字 IP 与技术机会 |
| 财富与自由 | 梳理现金流、财富目标、选择权与稳定性 |
| 健康与复利 | 整理习惯与记录，安排可持续的观察与调整 |
| 体验与创造 | 讨论关系、人生体验、作品和休息的取舍 |

- **全面盘点**：“七个方面都看看，帮我确定现在最该做什么。”
- **具体问题**：“我要不要换城市？收入、家人和生活节奏怎么取舍？”
- **定期复盘**：“这是本月计划和实际记录，帮我调整下一步。”

也可问访谈观点。技能保留个人经历与普遍事实的区别，不模仿嘉宾口吻，不把“黄毛思维”变成反对越多越正确，也不照搬 Crypto 配置或健康经验。来源、主题范围与解释限制随完整技能安装，离线仍可读取。

## 这些方法如何帮你做决定

| 处境 | 用到的方法 | 会得到什么 |
|---|---|---|
| 想坚持一件大家反对的事 | 黄毛思维 | 区分情绪评价、可验证问题和责任冲突，给有条件的坚持决定 |
| 学习或资料在换工具后难以延续 | AI 化 | 用最小背景记录和实际学习产物，改进下一次判断 |
| 环境变化，考虑迁移或调整方向 | 逐水草而居 | 比较换路条件、迁移成本、关系责任与保持稳定的价值 |
| 准备换职业、城市或投入项目 | 先探图 | 找一个会改变选择的未知，用小调查或体验获取信息，再决定投入 |
| 收入不错但很累，计划越排越满 | 身体维护 | 看真实日程和恢复冲突，明确缩减什么，而非不断添加任务 |
| 财富目标完成，却不知道下一步 | 玩家心态 | 找偏好样本，试一个可逆支线任务，体验后再决定是否深入 |
| 期待更多钱解决生活问题 | 财富是放大器 | 拆出资金能改变的部分，以及仍需协商或行动的环节 |

方法名对应实际提问、选择和反馈，不要求用户先学完访谈。完整步骤随技能安装；七个主题全部保留。

## 五个技能

| 技能 | 用途 | 典型指令 |
|---|---|---|
| [`sungemode`](skills/sungemode/SKILL.md) | 七主题人生经营入口，兼容原项目流程 | “开启孙哥模式，帮我判断下一步做什么” |
| [`sungemode-profile`](skills/sungemode-profile/SKILL.md) | 个人档案：目标、能力、资源与生活约束 | “整理我的现状，建立可移交的档案” |
| [`sungemode-scout`](skills/sungemode-scout/SKILL.md) | 机会开图：客户、替代、渠道与成本 | “给这个项目想法开图” |
| [`sungemode-experiment`](skills/sungemode-experiment/SKILL.md) | 行动实验：假设、预算、指标与停止条件 | “设计一个七天最小验证” |
| [`sungemode-review`](skills/sungemode-review/SKILL.md) | 复盘：人生或项目计划对照实际，更新判断 | “根据这周的结果调整下一步” |

每个技能可以独立安装和使用。`sungemode` 自身包含七主题与完整项目流程，不依赖其他四个技能；按需安装可减少技能列表的重复匹配。

## 安装

需要 Python 3.9+。安装脚本只用标准库，不下载依赖、不要求 API Key。macOS/Linux 使用 `python3`；Windows 可使用 `py -3` 替换。

```bash
git clone https://github.com/shuyixiao-better/sungemode-skills.git
cd sungemode-skills

# 查看技能；预览安装，不写文件
python3 scripts/install.py --list
python3 scripts/install.py --agent codex --scope user --dry-run

# 给 Codex 安装，默认中文；在所有本地项目中使用
python3 scripts/install.py --agent codex --scope user

# Claude Code / Qoder（按需选一条）
python3 scripts/install.py --agent claude-code --scope user
python3 scripts/install.py --agent qoder --scope user

# 仅安装完整入口到指定项目，也可以重复 --agent 同时安装到多个工具
python3 scripts/install.py --agent codex --agent claude-code --scope project --project /path/to/your-project --skill sungemode

# 安装完整英文入口（在另一个项目中示范）
python3 scripts/install.py --agent cursor --scope project --project /path/to/english-project --lang en
```

`--scope` 默认是 `project`，项目路径默认为运行命令时的目录；给其他项目安装时使用 `--project`。若想所有项目通用，明确使用 `--scope user`。可重复 `--skill` 选择多个技能。

安装后新开会话或按工具提供的方式刷新技能，确认技能列表里出现 `sungemode`。Codex 可以用 `$sungemode`；Claude Code 和 Qoder 可以用 `/sungemode`。也可以直接说“开启孙哥模式”。具体安装位置、调用差异及官方依据见 [工具兼容说明](docs/compatibility.md)。

### 支持哪些工具

安装器包含 Codex、Claude Code、Qoder、Cursor、GitHub Copilot、Gemini CLI 和 OpenCode 的官方目录规则。技能采用 [Agent Skills 标准](https://agentskills.io/specification)，不依赖某个厂商的专用运行工具。目录与格式适配经过本地测试；各产品的实际加载和模型表现需在对应版本中验证。

其他支持 `SKILL.md` 的工具可以指定目录：

```bash
python3 scripts/install.py --dest /path/to/agent/skills --skill sungemode
```

### 中英文如何切换

- 默认安装 `SKILL.md` 中文入口和中文 Codex 界面元数据，输出默认简体中文。
- `--lang en` 将 `SKILL.en.md` 作为安装后的 `SKILL.md`，并选用英文界面元数据；英文安装默认英文。
- 两种安装都保留中英文模板和参考资料，文件名、技能名与记录路径一致。
- 用户在对话中明确说“请用英文回答”或“请用中文回答”，技能遵从该偏好，无需重新安装。

### 已有安装、升级与卸载

相同内容重复安装会跳过；存在不同内容时整批安装在写入前拒绝，保护已有修改。切换安装语言或升级时，先把目标的 `sungemode*` 技能目录移到技能搜索目录之外的备份位置，再安装；备份保留原文件，失败时可移回。卸载只需移走对应技能目录，个人记录独立保存。

## 用 Markdown 让不同 Agent 接着做

需要保存时告诉 Agent “把记录保存在 `.sungemode/`”。单纯咨询默认在对话交付，不自动建立个人记录。

```text
.sungemode/
├── README.md
├── profile.md
├── life.md                  # 七主题现状、取舍、共享行动计划
├── reviews/2026-10-09.md     # 人生经营复盘
└── projects/my-project/     # 有具体项目时才创建
    ├── opportunity.md
    ├── experiment.md
    └── reviews/2026-10-09.md
```

换工具后可以说：“读取 `.sungemode/README.md` 和相关记录，继续当前计划。”个人综合复盘与项目复盘分别保存，原有项目记录无需迁移。记录放在工作项目，技能文件放在工具目录。仓库的 `.gitignore` 忽略自身的 `.sungemode/`；在其他项目保存私人记录时按需要配置该项目的忽略规则。

## 项目结构与验证

```text
skills/<name>/
├── SKILL.md                # 默认中文入口
├── SKILL.en.md             # 完整英文入口
├── agents/openai*.yaml     # Codex 中英文界面元数据
├── assets/                 # 中英文输出模板
└── references/             # 按需加载的参考（完整入口）
scripts/                    # 安装与检查
examples/                   # 中英文人生盘点与七天验证演示

tests/                      # 安装行为测试
docs/                       # 兼容与来源说明
```

```bash
python3 scripts/validate.py
python3 -m unittest discover -s tests -v
```

检查覆盖中英文入口、元数据、相对资源链接、安装语言、重复安装与冲突保护。GitHub Actions 配置了 macOS/Linux/Windows、Python 3.9/3.13 的检查矩阵；远程 CI 状态以实际运行结果为准。Skill 的决策表现按 [评估说明](evals/README.md) 验证，结构检查不能替代实际使用。
