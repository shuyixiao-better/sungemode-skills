# 人生盘点演示（虚构，非实际运行结果）

本例是维护者编写的输出示意，未进行真实咨询、健康评估或客户调研，不作为模型行为已通过的证据。

## 用户输入

我做了五年开发，不想辞职，想探索 AI 副业，也想学习和给家人留时间。扣除工作、照护和必要休息，每周还有七小时；新增行动预算 200 元。平时已有散步习惯，希望保持。财务只讨论这个预算，不提供资产和收入。先给一个两周计划，不用保存文件。

## 当前判断

可以把已有开发能力用在一个小的学习产物和机会调查上，先确认可触达对象与问题。不能从五年开发经历推出商业需求成立，也没有资料判断整体健康或财务状况。两周先按每周七小时安排，不新增订阅、不辞职。

## 七主题现状

| 主题 | 现状与依据 | 未知或限制 |
|---|---|---|
| 认知 | 用户希望探索；“AI 副业值得做”是待验证假设 | 先找一个可能推翻想法的观察，不以热度作证 |
| 决策 | 用户明确不辞职 | 比较维持现状、仅学习、学习并小范围调查 |
| AI 与知识 | 用户自述五年开发经验 | 实际 AI 能力与工具条件未知；先做小产物 |
| 商业 | 有探索意愿 | 客户、付费理由、渠道和交付成本均待确认 |
| 财富 | 新增预算上限 200 元 | 其余暂不讨论，不估算财富自由年限 |
| 健康 | 用户已有散步习惯，希望保持 | 不判断身体状态、不新增训练或治疗建议 |
| 体验与创造 | 用户想给家人留时间，并愿意学习 | 家人的安排和意愿要协商，不能默认已同意 |

## 优先行动与共享预算

下表按每周安排；第二周根据第一周反馈调整，但仍不超上限。这里的时间是计划上限，现金为拟议支出，不是实际花费。

| 行动 | 每周时间 | 新增现金 | 观察/调整条件 |
|---|---:|---:|---|
| 做一个能自己解释并演示的小工具，包含学习和准备 | 3 小时 | 0 元 | 已有工具无法完成时缩小任务，不自动订阅 |
| 整理一个目标人群的问题与替代方案 | 2 小时 | 0 元 | 无来源的结论标待验证；没有可触达对象则先研究触达，不编客户反馈 |
| 与家人协商一次共同活动 | 0.5 小时 | 0 元 | 包含协商；双方不方便就另约，不强行执行 |
| 简短记录现有散步和日程，不改变已有习惯 | 0.5 小时 | 0 元 | 不从短期记录推断医疗效果 |
| 合并复盘、记录判断变化与安排下一周 | 1 小时 | 0 元 | 对照实际投入；未完成先分辨任务太大还是时间估计不准 |
| **合计** | **7 小时** | **0 元** | **现金剩余 200 元，时间无余量** |

优先推进前三项，后两项是共同记录与复盘成本。必要工作、照护、休息和原有散步时间已按用户输入排除在可用七小时之外。若实际有未计入的责任，先减少工具任务，不占用恢复。两周拟议总投入 14 小时、0 元；200 元上限按用户本次新增行动预算理解，仍未使用。

## 两周后检查什么

- 学习：是否有可演示产物，是否能解释关键部分；没有产物不等于完全没学会。
- 商业：是否能指出有来源的真实问题、替代方案与下一步接触路径；目前不声称需求或付费已验证。
- 关系与负担：共同安排是否双方认可，计划是否挤占休息和责任。
- 判断：哪些假设被支持、被削弱或仍未知；决定继续、缩小或暂缓。

上述条件是本项目提出的检查方法，用户尚未确认的部分保留为提案。本次只在对话交付，没有建立档案、调用其他模型、联系客户或自动设置提醒。
